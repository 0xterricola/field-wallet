# Field Wallet

A privacy-preserving wallet and provider SDK for Logos Execution Zones.

Field aims to provide:

- Public and private LEZ accounts
- Local wallet creation, import, backup, and recovery
- Multiple accounts and account switching
- Asset balances and transfers
- Wallet Provider SDK for Logos applications
- Explicit connection and transaction approval flows
- Logos Basecamp integration
- CLI tooling
- Keycard hardware-wallet support
- Faucet and testimonial reference applications

Built toward the requirements of Logos λPrize LP-0021.
